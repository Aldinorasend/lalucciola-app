# Glossary

| Term | Meaning |
|---|---|
| **Booking / Reservation** | A guest's reserved table(s) at a date and time. Used interchangeably. |
| **Cover** | One guest. A party of 4 = 4 covers. |
| **Party size** | Number of covers in a booking. |
| **Slot** | A fixed time block (e.g. 30 min) used for start times and capacity limits. |
| **Slot capacity** | Max covers that may *start* in one slot (kitchen pacing), separate from table seats. |
| **Area** | A section of the room (e.g. Indoor, Terrace). Groups tables. |
| **Table** | A physical table with a number and seat capacity (min/max). |
| **Walk-in** | A guest without a booking who is seated right away. Recorded as a booking with source `walk-in`. |
| **Waitlist** | A queue of guests waiting for a table to free up. |
| **No-show** | A booked guest who never arrived. |
| **Item** | A stock-kept product: a raw ingredient or a beverage. |
| **Unit** | How an item is measured: kg, g, L, ml, pcs, bottle. |
| **Batch** | A quantity of an item received together, with its own expiry date and unit cost. |
| **Stock movement** | Any change to stock: receive (in), usage, waste, count adjustment. Never edited, only reversed. |
| **Min level** | Threshold below which an item is flagged as low stock. |
| **Stock value** | Quantity on hand × unit cost, in IDR. |
| **Stock count / stock-take** | A physical count. The difference from the system quantity is booked as an adjustment. |
| **Recipe** *(future)* | Ingredients and quantities per menu item, used for automatic deduction. |
