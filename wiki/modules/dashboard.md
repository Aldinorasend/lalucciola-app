# Dashboard: Today overview

The first screen after login. It answers "what's happening today?" at a glance.

## Widgets (proposed)
| Widget | Content |
|---|---|
| Today's covers | Booked covers vs. total seats in open sections; seated now |
| Upcoming bookings | The next ~2 hours as a list (time, name, party, table, status), with quick Seat / No-show actions |
| Tables now | Count of free / seated / reserved-soon tables, linking to the [tables display](floor-plan.md) |
| Waitlist | Number of parties waiting and the longest wait |
| Low stock | Items below their min level (linking to [inventory](inventory.md)) |
| Expiring soon | Batches that expire within the warning window |
| Stock value | Total inventory value in IDR (**Owner/Manager only**) |

The booking and inventory widgets read from separate modules (D-013). The dashboard only displays them side by side.
